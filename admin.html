Keeping the site going

Written for classmates who are not web developers. One file does most of the work.

The short version. Almost everything you will ever change lives in js/config.js. Open it in Notepad (Windows) or TextEdit (Mac), change the words inside the quotes, save, and upload that one file back to GitHub. You do not need to touch the other files for passcodes, email, Facebook, Google Forms, Spotify, or the next reunion date.

Before you publish

  1. Change the passcode in js/config.js from the starter code to something only the class will guess. Share it at a gathering, in the Facebook group, or by email — not in a public post.
  2. Put a committee email in contactEmail so “Open in Email” works. Until you do, classmates can still write a note and copy it.
  3. Paste the Facebook group link if you have one.
  4. Form share links (Jotform) are already in js/config.js. To replace one later, paste the new Share link into the matching line under forms.
  5. Optional: create a public Spotify playlist and paste only the playlist ID (the letters after /playlist/).
  6. After the site is live, paste the public web address into siteUrl so shared links show the crest picture.

How to put this on GitHub Pages

1
Create a free GitHub account if you don’t have one. Create a new repository. If you want the address yourname.github.io, name the repository exactly yourname.github.io. Otherwise any name is fine (the address will be yourname.github.io/that-name).
2
Upload the contents of this folder — index.html, the css, js, and assets folders — not a zip file sitting in a subfolder. GitHub Pages looks for index.html at the top.
3
In the repository, open Settings → Pages. Under Source, choose Deploy from a branch, branch main, folder / (root). Save. Wait a minute or two.
4
Visit the address GitHub shows you. If a page looks old, give it a couple of minutes — Pages is not instant. Then paste that address into siteUrl in js/config.js and upload the file again.

The five class forms

These are live. Each button on the site opens the matching Jotform. Submissions go to SHSClass86@proton.me.

  • Update my classmate page
  • Add songs to the mixtape
  • Memorial note
  • Send a photo
  • Next gathering (interest only — not a real RSVP)

To swap a form, copy its Share link from Jotform and paste it over the old one in js/config.js under forms. Leave a line as "" and that button falls back to email.

Everyday updates

  • Change the passcode — edit passcode in js/config.js.
  • Announce a date — edit the three lines under nextGathering.
  • Add an announcement — open community.html, find an existing announcement-card, copy the whole block, change the words between the tags. Don’t delete the
    pieces.
  • Add a reunion photo — drop a .jpg in assets/reunion40/ (or a new folder), then copy one of the lines in memories.html and point it at your new file.
  • Add a classmate to the roster — add a portrait to assets/classmates/ and a new line to the list at the top of js/roster.js.
  • Put a life update on someone’s page — in that person’s line in js/roster.js, add bio: "A short paragraph." before the closing brace.
  • Add someone to the memorial — copy a card in memorial.html and add inMemoriam: true to that person in js/roster.js.

What this site will not do (on purpose)

GitHub Pages is a free stack of files. It cannot log people in, store RSVPs, or save a profile that other classmates will see. Those things need a Google Form or an email. This site is honest about that — there are no fake “submit” buttons that pretend a head-count is happening.

The classmate passcode is a courtesy lock. Anyone who knows how to view the settings file can find it. That is normal for a free GitHub Pages site. Share the code with the class, not the internet.

The classmate roster is the 1986 yearbook list: 63 senior portraits plus 8 classmates marked “not pictured” (71 names). That count is intentional — do not trim it to a different class-size number. Classmates without a yearbook portrait keep the “Not pictured, 1986” note. Life updates stay empty until a classmate writes in and you paste a short bio on their line in js/roster.js. Six roster names are marked in memoriam, and the memorial page also honors Michael D. Hartzler, a Smithville classmate through 8th grade.
